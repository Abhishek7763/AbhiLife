# AbhiLife Design Direction

## Calm Minimal Personal OS

This is the locked visual direction for AbhiLife from v0.11.0 onward.

Principles:
- Quiet interface, strong system.
- Mobile-first and comfortable for daily long-term use.
- Warm neutral surfaces with subtle borders, no hard shadows.
- Muted semantic color only for focus, completion, attention and errors.
- System typography and local/offline-safe assets only.
- Four primary destinations: Today, Inbox, Goals, More.
- Habits, Maintenance, Reviews, History and Notes belong under More unless future usage proves they deserve primary navigation.
- Today answers one question: what matters now?
- Complex goal workflows use focused screens/modals instead of an endless dashboard.
- Dark mode follows system appearance and stays low-contrast rather than neon.
- No percentage life scores, XP, streak pressure, decorative charts or motivational clutter.

The functional offline storage, recovery, goal investigation, goal definition, goal breakdown, activation and Today execution engines remain independent from this presentation layer.
